# E-Commerce Sales Analysis

## Project Overview

Analyzed 18,000+ e-commerce transactions to identify sales trends, customer purchasing behavior, and seasonal demand using SQL and Tableau.

## Business Problem

The company wanted to understand:

• Which months generated the most revenue?
• Which products sold best?
• What customer segments drove sales?

## Tools

- SQL
- Tableau
- Excel

## Process

1. Imported data
2. Cleaned missing values
3. Wrote SQL queries
4. Created Tableau dashboard
5. Generated business recommendations

## Results

• November generated the highest sales.
• Home & Living produced the highest revenue.
• Holiday demand increased substantially in Q4.
